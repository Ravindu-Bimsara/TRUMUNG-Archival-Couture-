## Overview

**TRÜMUNG** is an editorial-style luxury fashion website crafted for high-end fashion ateliers and archive collections. It blends minimal brutalist layouts with high-fashion typography, seamless interactions, and functional client-side e-commerce features.

---

## Key Features

* **32-Item Archival Catalog**: Curated piece catalog spanning *Outerwear*, *Tailoring*, and *Accessories*.
* **Smart Dynamic Pagination (Load More)**:
  * Renders 8 archival pieces on initial page load.
  * Clicking **"Load More"** dynamically appends the next 8 items with smooth fade-in transitions.
  * Live visual progress bar displaying displayed vs. total collection items.
* **Instant Category Filtering**:
  * Filter pieces across All Archival, Outerwear, Tailoring, and Accessories.
  * Automatically resets pagination counter to 8 when category switches.
* **Live Multi-Currency Engine**: Instant price conversion across **USD ($)**, **EUR (€)**, **GBP (£)**, and **JPY (¥)** using real-time DOM updates.
* **Slide-Out Shopping Bag**:
  * Persistent interactive side drawer.
  * Add to bag, item removal, live count badge, and automated subtotal calculation.
* **Dual-City Hero Monolith**: Interactive split-screen viewport spotlighting studios in *East Village (NYC)* and *Koreatown (LA)* with hover reveal effects.
* **Synchronized World Studio Clocks**: Real-time hours for Paris, New York, and Los Angeles ateliers.
* **Editorial Sections**:
  * Martin Schleifer Capsule Spotlight.
  * High-Fashion Runway Video/Visual Teaser.
  * Editorial Gazette & Press Critic reviews (NYT Style, Vogue Archive, Highsnobiety).
  * Bespoke VIP Fitting Concierge booking interface.
